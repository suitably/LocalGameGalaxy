# Game catalog

Games live in `src/games/<id>/` and are registered by hand in [`src/lib/gameRegistry.tsx`](../../src/lib/gameRegistry.tsx) (lazy-loaded entry component, route, category, colours, i18n title/description keys). The hub renders the registry; there is **no auto-discovery** and no per-game manifest. New games start from `node scripts/scaffold-game.mjs` ([scripts/README.md](../../scripts/README.md)), which generates the layout the existing games use and patches the registry, `STORAGE_KEYS` and both locale files.

Numbers below are a snapshot (2026-10-18). Re-derive them before relying on them — commands at the end.

## 1. Registry and size

Registry order = hub order. The dice games in `DICE_GAMES` (`src/games/tabletop/logic/tableCatalog.ts`: qwixx, knister, kniffel) are filtered out of the hub (`Hub.tsx`) and listed on the Spieltisch; Knister can also be played with everyone on their own device (`?room=`, `KnisterEntry` → `KnisterRoomGame`, rules in `logic/knisterRoom.ts`: one roll for everyone, the next roll once all placed it) (tabletop lobby) instead; their registry entries and routes stay. The card games with enforced rules (Schwimmen, Durak, Arschloch, Skat, Mau-Mau, Schwarzer Peter, Golf, Cabo) have no hub entry at all: they are rule scripts of the Spieltisch (`CARD_GAMES`, [tabletop-scripted-games](tabletop-scripted-games.md)); the `cards` score tracker ("Kartenspiel-Zähler": scores, lives, bids for games played with real cards) is listed on the Spieltisch under "Punktezähler" (`SCORE_TRACKERS`) and filtered out of the hub like the dice games; its registry entry and route stay ([migration plan](../tasks/CARD-GAMES-TO-SPIELTISCH.md)).

Melodiq's TV and queue channels (`logic/syncChannels.ts`) run on `useMultiChannelSync` with `selfEcho: false`. Protocol details: [sync-protocol.md](sync-protocol.md).

A cast TV (Presentation API) runs in its own storage partition and only gets JSON over the `PresentationConnection`, so file handles and `blob:` URLs do not survive. Local-folder media travels as acknowledged binary chunks before `PLAY_SONG` (`src/games/melodiq/logic/tvMediaTransfer.ts`, `MEDIA_START` / `MEDIA_ACK` / `MEDIA_END`), and server media paths are sent as absolute URLs with the token. A popup TV window shares the host's storage and does not need this.
