- **Spieltisch: Lua scripts of Workshop games can run on the host (experimental)**: for an imported Tabletop Simulator game with scripts, the game menu offers "Run Lua scripts (experimental)". The scripts then run sandboxed on the host device only (Lua 5.4 in a background worker, loaded only when switched on): setup buttons, `onLoad`, waits and the common table events work, every change reaches the phones as a normal table update, and script state is kept in the table's saves. A script log lists printed lines, errors and TTS calls that are not supported yet. Off by default.
