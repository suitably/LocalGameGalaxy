- **Melodiq setting "Rows per Lyric"**: choose whether a lyric prefers 1 row or long lines wrap onto 2 rows, which keeps the text larger (default). Text shrinks only down to the new **Minimum Lyrics Size** (40–100 %, default 60 %): a line that is too long then wraps instead, only between words. Also available in the remote host settings, and it reaches a cast TV.
