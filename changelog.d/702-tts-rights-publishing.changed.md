- **Imported Tabletop Simulator games are shared on your companion server, never published**: with a companion server, an imported Workshop game is saved there for everyone who uses that server, and the server downloads its images, so other devices load them from the server (the same approach as Melodiq songs). The companion server now accepts BSON saves (most Workshop mods). The import dialog shows the Workshop source, the author's Steam profile and a rights notice. Imported games can no longer be submitted for publishing, and copies on the companion server stay marked as imports when they are overwritten.
