- **Imported Tabletop Simulator games stay private copies**: the import dialog shows the Workshop source, the author's Steam profile and a rights notice; imported games can no longer be submitted for publishing; a copy saved on the companion server is marked private to that server and stays so when overwritten. The companion server no longer stores downloaded Workshop saves in its library and now accepts BSON saves (most Workshop mods), so importing through the companion works exactly like importing in the browser.
