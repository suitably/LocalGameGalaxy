- **Tabletop: game menu in the app header**: the running table no longer has its own floating menu button. Back (to the game list, or on the TV host back to the party lobby), rules, save game, table settings and restart are in the header like in every other game; on phones they sit in the header menu. Only the canvas tools (edit, undo/redo, zoom, fit, selection) stay on the table, and the selection bar no longer covers the editor toolbar. Timer and counter buttons and card backs have screen-reader labels.
