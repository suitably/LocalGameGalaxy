- **Draw pot (Lostopf)**: a new hub entry to draw names, teams or anything else via a shared link. The host types the entries (one per line, `Name *3` for several copies, a helper builds balanced groups), chooses whether drawn entries leave the pot, whether people may draw several times (with a limit or unlimited), whether participants see the pot's contents and whether the host sees the results, then shares the link or QR code. Each participant draws on their own device; results and a history of all draws stay in the browser. A secret santa mode lets everyone pick their own name and draw exactly one other person (fixed assignment, nobody draws themselves). The host can stop drawing, reset or delete the pot; pots are stored in a Cloudflare Durable Object and deleted after 60 days. When a Nexumia server is connected, the host can store the pot there instead (plugin `drawpot`, on by default; the link carries the server address, pots are files in `config/drawpots/`).
