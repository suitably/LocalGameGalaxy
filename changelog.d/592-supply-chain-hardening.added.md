- **Verifiable releases** (#592): every release asset (APK, server archives) and every Docker image carries a build provenance attestation, so `gh attestation verify <file> -R suitably/LocalGameGalaxy` proves it was built by this repository's release workflow. Releases also ship CycloneDX SBOMs for the app, the companion server and the signaling tracker. Images are published to GitHub Container Registry (`ghcr.io/suitably/nexumia-server`, `ghcr.io/suitably/galaxy-signaling`) as well as Docker Hub. A release now fails on an unaccepted high or critical advisory in a production dependency (allow-list: `scripts/audit-allowlist.json`); on PRs the audit stays advisory.
