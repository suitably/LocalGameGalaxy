- **Signaling built into the Nexumia server**: the companion server now answers WebRTC signaling itself at `/signaling` on its normal port. A server reachable through a reverse proxy or tunnel is used for the host ↔ phone pairing automatically (before, the app looked for a separate tracker on port 8000, could not use it from the hosted app and fell back to public trackers). The server keeps the signaling sockets alive behind proxies that close idle connections. Only the pairing passes through the server; audio and game data stay peer to peer.
