### 📋 Implementation Plan: Game: Dart Checker

Hello! I have reviewed the issue and your request to build a Darts Checker game to track scores during a match. You also asked: **"Was ist denn best practice?" (What is the best practice?)**

For dart tracking (e.g., 301/501), the best practice is:
1. **Inputs:** A numeric keypad (1-20, Bull, Miss) along with multipliers (Single, Double, Triple).
2. **Game Modes:** Start with a specific score (e.g., 501 or 301) and count down to exactly 0. You requested "auf oder abzählen" (counting up or down), so I will also include a mode starting from 0 and counting up indefinitely.
3. **Finish:** In typical X01 countdowns, ending on a "Double" is standard, but I can make this a toggleable setting if you'd like a simpler "Straight Out" (any score to finish). Let me know if you want the Double-Out rule enforced strictly.
4. **Legs/Sets (Optional):** Usually, a match is played Best of X Legs. I'll stick to basic point tracking per leg for now to keep it straightforward, as per your request.

1. **Create the Darts Module (`src/games/darts`):**
   - **`DartsGame.tsx`**: Main view and layout orchestrator.
