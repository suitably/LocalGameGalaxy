# Galaxy Push Relay (Cloudflare Worker)

Zero-cost, 24/7 standalone Web Push Relay for LocalGameGalaxy (e.g. GuessArt closed-browser push notifications).

## 🚀 Quick Deployment (1-Command)

From this directory:

```bash
npx wrangler deploy
```

Once deployed, copy your worker URL (e.g. `https://galaxy-push-relay.<your-subdomain>.workers.dev`) into **Settings ➔ Server** or use it as your Host Game Relay.
